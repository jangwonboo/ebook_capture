# Markdown Reader — 웹 리더

캡처 파이프라인이 만든 책 Markdown을 브라우저에서 읽는 앱입니다. 설치·빌드·서버가 없습니다. 기획과 동작 세부는 [SPEC.md](SPEC.md).

## 열기

1. `reader/index.html`을 Chrome이나 Edge에서 엽니다(더블클릭).
2. **폴더 열기**로 책 폴더(`{title}.md`와 `assets/`가 있는 곳)를 고르고, 쓰기 권한을 허용합니다.
   - 그림이 보이고, 주석이 책 폴더의 `{title}.notes.json`에 저장됩니다.
   - **파일 열기**나 끌어다 놓기로 열면 그림 없이 읽기만 되고, 주석은 브라우저에만 남습니다. 주석 패널의 "브라우저에만 저장됨"을 누르면 폴더 저장으로 바꿀 수 있습니다.

인터넷이 끊겨 있어도 읽기와 주석은 됩니다. 글꼴 일부와 AI 문답만 인터넷이 필요합니다.

## 화면

- 왼쪽: 목차 / 검색 / 저장 탭. 상단 왼쪽 패널 아이콘(왼쪽이 찬 사각형)으로 접기
- 가운데: 장 하나씩. 스크롤하면 목차의 현재 위치가 따라옵니다
- 오른쪽: 상단 오른쪽 끝 패널 아이콘(오른쪽이 찬 사각형)으로 여닫는 주석 패널. 아이콘 옆 숫자는 주석 개수
- 패널 너비: 양쪽 패널 경계선 가운데의 손잡이를 끌면 됩니다. 두 번 누르면 기본 너비(목차 290px, 주석 360px)로, 손잡이에 포커스를 두고 ←/→를 누르면 16px씩 바뀝니다. 가운데 본문은 최소 360px를 남깁니다
- 위: 글꼴, 문단 폭(좁게/넓게), 글자 크기(가−/가+), 테마(◐), 설정(⚙)
- 문단 폭: 본문 영역 대비 기본 70%이고 좁게/넓게(또는 `[`/`]`)로 10%씩 바뀝니다. 한 줄이 약 20–50자가 되도록 본문 영역 너비와 글자 크기에 맞춰 범위(30–100% 안)가 정해지고, 버튼에 마우스를 올리면 지금 범위가 보입니다. 패널을 열거나 글자를 키워 범위를 벗어나면 화면에는 범위 안 값을 쓰고, 다시 넓어지면 고른 값으로 돌아갑니다
- 글자 크기: 본문은 기본 14pt이고 가−/가+(또는 `-`/`+`)로 1pt씩 바뀝니다(9–24pt). 목차·검색·저장·주석 패널과 메뉴는 12pt Pretendard로 고정입니다

## 단축키

| 키 | 동작 |
| --- | --- |
| ← / → | 이전 / 다음 장 |
| `/` | 검색 |
| `+` / `-` | 글자 크기 (1pt씩) |
| `[` / `]` | 문단 폭 (10%씩) |
| `H` | 선택한 문장 칠하기 (마지막에 쓴 색) |
| `M` | 선택한 문장에 메모 |
| `E` | 이 장 편집 |
| `Ctrl+S` | 편집 중 저장 |
| `A` | 선택한 문장을 AI에게 묻기 |
| 목차에서 ↑ ↓ ← → Enter | 항목 이동, 펼침/접힘, 열기 |

## 주석

문장을 드래그하면 색 4개, 메모, AI(묻기), 복사가 뜹니다. 주석 카드는 14pt Pretendard로 보입니다. 메모에 `#태그`를 쓰면 패널에서 태그로 거를 수 있습니다. 패널 아래에서 Markdown·JSON으로 내보내고 JSON을 가져옵니다.

## AI 문답

1. ⚙ 설정에서 Anthropic API 키를 넣고 모델을 고릅니다(기본 Claude Sonnet 5.5).
2. 문장을 고르고 선택 도구의 "AI"(또는 주석 카드의 "AI에게 묻기")를 누른 뒤 질문합니다. 책마다 처음 한 번 전송 범위 안내에 동의합니다.
3. 답 아래 "근거" 버튼을 누르면 원문으로 갑니다. 마음에 드는 답은 "주석으로 채택"합니다.

질문할 때 고른 문장과 지금 장의 본문 전체, 책 제목·목차, 그 주석의 이전 문답이 Anthropic API로 갑니다. 사용료는 입력한 키의 계정에 청구됩니다. 키는 주석 파일이나 내보낸 파일에 들어가지 않습니다. 공용 PC에서는 설정의 "이 브라우저에 키 저장"을 끄세요.

## 편집

1. 읽던 장에서 본문 위 **편집** 버튼(또는 `E`)을 누릅니다. 그 장이 편집기로 바뀌고, 보던 문단이 편집기 맨 위에 그대로 옵니다. 편집을 끝낼 때도 편집기에서 보던 자리로 읽기 화면이 돌아옵니다.
2. 렌더링된 모양 그대로 고칩니다. 커서가 들어간 곳만 Markdown 기호(`**`, `##`, `$$`)가 보입니다. 수식·표는 블록을 누르면 원문과 미리보기가 같이 열립니다. 툴바 끝 버튼으로 원문 보기와 오갈 수 있습니다.
3. 편집 중에는 **편집** 버튼 자리에 "편집 중" 표시, 저장 상태, "변경 보기", "저장", "편집 끝" 버튼이 나옵니다. `Ctrl+S`로도 저장합니다. "변경 보기"로 저장될 줄을 먼저 볼 수 있습니다.

- 저장은 책 폴더의 `{title}.md`에 합니다("폴더 열기"로 연 경우). 고치지 않은 줄은 한 글자도 바뀌지 않습니다.
- 처음 저장할 때 `{title}.original.md`가 생기고, 저장할 때마다 직전 판이 `.reader/history/`에 남습니다(최근 20개).
- "파일 열기"로 연 책은 수정본을 내려받습니다.
- 편집기는 처음 쓸 때 인터넷에서 불러옵니다(Vditor 4.0.1).
